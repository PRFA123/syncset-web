# PROJETO: PESQUISA E ANÁLISE ESTRATÉGICA DE DOMÍNIOS

## OBJETIVO PRINCIPAL

Realizar uma pesquisa completa de 50 nomes de domínio para um novo projeto, verificando disponibilidade em múltiplas extensões e entregando um relatório estratégico com recomendações de aquisição.

\---

## INSTRUÇÕES PARA O CLAUDE

### FASE 1: GERAÇÃO DE NOMES (50 NOMES)

**Metodologia de Geração**:

1. **Palavras-Chave Base** (20 nomes):

   * Use combinações das seguintes categorias:

     * **Ação**: build, create, craft, design, develop, innovate, launch, spark, ignite, evolve
     * **Qualidade**: prime, core, apex, peak, vital, keen, bold, pure, true, nova
     * **Conceito**: nexus, hub, lab, studio, forge, works, collective, society, guild, alliance
   * Combine 1 palavra de Ação + 1 de Qualidade ou Conceito
   * Exemplos: `buildprime`, `createhub`, `corelab`, `apexstudio`, `igniteworks`
2. **Nomes Curtos e Memoráveis** (10 nomes):

   * 1-2 sílabas, 4-6 caracteres
   * Palavras inventadas ou combinações únicas
   * Exemplos: `zenth`, `klyde`, `vorta`, `nexum`, `prysm`, `trove`, `velox`, `aethr`, `zyon`, `cova`
3. **Descritivos e Funcionais** (10 nomes):

   * Relacionados ao propósito do negócio
   * Exemplos: `smartflow`, `datavault`, `cloudpeak`, `codeforge`, `designcore`, `techaxis`, `datapulse`, `logicraft`, `visionary`, `strativ`
4. **Premium e Aspiracionais** (5 nomes):

   * Nomes com alto valor de marca
   * Exemplos: `noble`, `legacy`, `summit`, `vanguard`, `paramount`
5. **Global/Internacional** (5 nomes):

   * Palavras com significado universal
   * Exemplos: `nexa`, `avrio`, `soleris`, `ventus`, `orizon`

**Regras para Geração**:

* ✅ Nomes de 4-12 caracteres (ideal: 5-8)
* ✅ Fáceis de pronunciar em inglês
* ✅ Sem hífens ou números
* ✅ Evitar combinações muito comuns (ex: "best", "top", "super")
* ✅ Priorizar nomes que funcionam como marca forte

\---

### FASE 2: VERIFICAÇÃO DE DISPONIBILIDADE

**TLDs a serem verificados** (em ordem de prioridade):

1. `.com` - PRIORIDADE MÁXIMA
2. `.io` - Popular para startups/tecnologia
3. `.ai` - Tendência para IA/tech
4. `.dev` - Para desenvolvedores
5. `.app` - Para aplicativos
6. `.co` - Alternativa ao .com
7. `.cloud` - Para serviços em nuvem
8. `.tech` - Para empresas de tecnologia

**Ferramentas de Verificação**:

1. **Namecheap Bulk Domain Search** (Principal)

   * URL: `https://www.namecheap.com/domains/bulk-domain-search/`
   * Permite verificar 50 nomes de uma vez
   * Mostra status: Available, Taken, Premium
2. **Instant Domain Search** (Secundário)

   * URL: `https://instantdomainsearch.com/`
   * Para verificações rápidas de nomes específicos
3. **WHOIS Lookup** (Confirmação)

   * Para validar disponibilidade quando houver dúvidas

**Processo**:

* Dividir os 50 nomes em 2 lotes de 25 para verificação
* Para cada nome, verificar status em cada TLD
* Registrar resultados: ✅ Disponível | ❌ Indisponível | ⚠️ Premium
