## 7\. Como Usar (Bootstrapping em 1 Comando)

Com a estrutura pronta, o fluxo de operação para qualquer projeto torna-se 100% autônomo.

1. **Torne os hooks executáveis:**

```bash
   chmod +x .claude/hooks/auto\\\_dispatch.sh core/orchestrator.py
   ```

2. **Inicie o Claude Code passando apenas o tema do seu projeto:**

```bash
   claude "Construa um sistema de automação para extrair dados do YouTube, gerar resumos com IA e enviar para um webhook no Discord"
   ```

### O que o Claude Code fará automaticamente a partir deste comando:

1. **Leitura e Hook**: O hook `.claude/hooks/auto\\\_dispatch.sh` é acionado e extrai o tema.
2. **Scout Autônomo**: O `orchestrator.py` consulta o GitHub API e identifica os repositórios com melhor pontuação para o tema (ex: `youtube-transcript-api`, `langchain`, etc.).
3. **Instalação Sem Intervenção**: Os projetos são clonados no diretório `workspace/` e suas dependências Python/Node são resolvidas e instaladas.
4. **Wiring \& MCP Registration**: O `wiring\\\_agent` varre os repositórios baixados, compila scripts de extração em skills do Claude Code e vincula os arquivos de configuração ao `.mcp\\\_runtime.json`.
5. **Multi-Agent Loop**: O `execution\\\_agent` monta a aplicação combinando as ferramentas baixadas, roda o pipeline, trata eventuais erros de execução e entrega o projeto funcional no diretório `workspace/`.
