SyncSet is a consulting + automation business, not a staffing agency or software vendor. "Marketing agency" best captures the service-delivery aspect ("we build your workflows") while staying true to the business model.

## ✅ VERIFICATION INSTRUCTIONS

### Primary Path: Postcard

Google will mail a postcard with a verification code to your GBP address.

**Steps:**
1. In GBP dashboard, claim your business
2. Choose "Verify by postcard"
3. Confirm or enter the address (for remote business: leave blank or use virtual office address if required)
4. Google mails postcard within 5–7 business days
5. Receive postcard, enter code in GBP dashboard
6. **Status: Verified** ✓

**Note on address:** SyncSet is remote-first. If Google requires a displayed address, you have two options:
- Leave it blank (if GBP allows) → profile shows "Serves the area" without a specific location ✓
- Use a virtual office or registered address temporarily, then remove it after verification → GBP will cache "Australia" / "Worldwide" from the schema instead

### Fallback Path: Phone Call

If postcard doesn't arrive or you need faster verification:

1. In GBP dashboard, choose "Verify by phone"
2. Google calls the provided phone number
3. Answer and confirm the 6-digit code
4. **Status: Verified** ✓ (usually within 1 hour)

### Post-Verification Checklist

Once verified, immediately:

- [ ] Upload cover photo (1200×630) — recommend website hero section
- [ ] Upload 3–5 service photos (no logo spam — show real workflows, team, etc.)
- [ ] Link website (syncset.com.au)
- [ ] Add Google Business Profile link to website footer (for bidirectional linking)
- [ ] Confirm hours of operation (set as appropriate AU timezone)
- [ ] Confirm phone number (or leave blank if using email-only contact)
- [ ] Enable messaging if desired (or leave contact via booking link)
- [ ] Verify all fields populated correctly (no typos, no duplicate categories)

## ⚙️ TECHNICAL FIXES REQUIRED (Before GBP Activation)

### Action 1: Patch `src/lib/schema.ts` — Remove Remote Mismatch

**File:** `src/lib/schema.ts` (lines 22–38)

**Current code:**
```typescript
export interface SchemaLocalBusiness {
  '@context': string;
  '@type': string;
  '@id': string;
  name: string;
  url: string;
  address: {
    '@type': string;
    addressLocality: string;
    addressRegion: string;
    postalCode: string;
    addressCountry: string;
  };
  areaServed: string[];
  priceRange: string;
  email: string;
}
```

**Issue:** Empty fields (addressLocality, addressRegion, postalCode) create schema that implies a physical location. Per business-profile-setup skill rule: "For a remote-first business, use only addressCountry."

**Fix:** Remove locality / region / postcode fields, keep only addressCountry.
